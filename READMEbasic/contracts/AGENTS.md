# READMEbasic Contract Agent Instructions

> **Scope:** `READMEbasic/contracts/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)

Agents MUST keep normative README obligations separate from examples, templates, research, and presentation resources.

- Use MUST/MUST NOT for binding requirements.
- Preserve rationale and evidence when a contract exists because of repeated documentation failures or research.
- Do not create a binding rule merely because one README template uses a section or style.
- Do not weaken a contract to accommodate stale or inaccurate README content.
- Material contract changes require deliberate review and [`../CHANGELOG.md`](../CHANGELOG.md) updates.
