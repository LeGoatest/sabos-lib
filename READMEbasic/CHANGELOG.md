# Changelog

All notable changes to READMEbasic will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/).

## [Unreleased]

### Added

- READMEbasic framework defining audience-first, evidence-based README structure.
- Binding `AGENTS.md` for automated README creation and maintenance.
- Reusable `TEMPLATE.md` with optional sections and verification rules.
- `best-practices.md` synthesizing GitHub guidance, established README projects, supplied examples, and empirical research.
- `resources.md` with curated official guidance, templates, examples, badge resources, changelog guidance, and README tooling.
- `contracts/` with contract-specific agent instructions and a binding README Integrity Contract.
- `positions/` with local agent governance as the explicit home for deliberate READMEbasic preferences/bias, rationale, tradeoffs, and divergence from common template conventions.
- `profiles/` as the governed home for application, library/package, monorepo, documentation/governance, and subsystem README specializations.
- `research/` for empirical and scholarly README/documentation evidence with local agent governance.
- `standards/` for formal specifications and platform-owned documentation behavior with local agent governance.
- `references/` for historical/comparative source material with provenance-preservation rules.
- `examples/` for illustrative README structures/case studies that do not become authority by existence.
- `glossaries/` with README/documentation terminology and nested agent instructions.
- This subsystem changelog.

### Changed

- Added READMEbasic to the repository root README and governance authority map.
- Established README facts such as commands, versions, paths, badges, and status as user-facing contracts that must be verified against repository evidence.
- Updated READMEbasic's canonical README and agent instructions to route badge/template/tooling decisions through the curated resource catalog.
- Clarified the separation between current-state README documentation and historical `CHANGELOG.md` content.
- Reframed READMEbasic as an evolving knowledge framework that separates practitioner guidance, explicit positions, profiles, research, standards, references, examples, resources, contracts, glossaries, templates, and agent governance.
- Added explicit routing through the README Integrity Contract before material automated README work.
- Added just-in-time routing through the nearest knowledge-domain `AGENTS.md` instead of loading every evidence source for every README task.
- Added explicit protection against treating popular template conventions as universal rules or silently replacing a documented READMEbasic position.
