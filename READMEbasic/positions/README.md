This directory records deliberate READMEbasic preferences separately from GitHub/platform behavior, formal Markdown specifications, research evidence, templates, examples, and binding README contracts.

Examples of suitable subjects include first-screen priority, progressive disclosure, manual table-of-contents use, badge restraint, README-versus-reference boundaries, and profile-specific ordering preferences.

A position does not become a binding README requirement automatically. Stable obligations should be adopted through [`../contracts/`](../contracts/README.md).
