# READMEbasic Contracts

> **Status:** Binding contract registry for READMEbasic

READMEbasic contracts define stable obligations that README authors, agents, and repository documentation should preserve.

Research, examples, templates, and external guidance may inform a contract, but the contract records the adopted READMEbasic position.

## Current contracts

- [`readme-integrity.md`](readme-integrity.md) — README claims must be supported by repository/project evidence and remain synchronized with user-facing behavior.

## Contract model

Contracts SHOULD identify scope, normative requirement, rationale, evidence basis, validation, exceptions, and related documentation where useful.

See [`AGENTS.md`](AGENTS.md) before automated contract changes.
