# READMEbasic Documentation Agent Instructions

> **Status:** Binding for automated work under `READMEbasic/docs/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)  
> **Knowledge index:** [`README.md`](README.md)

READMEbasic documentation preserves contracts, practitioner positions, profiles, research, standards/platform guidance, historical references, terminology, and synthesis without treating them as equally authoritative.

## Required routing

Before changing a subject:

1. Read [`../AGENTS.md`](../AGENTS.md).
2. Read [`README.md`](README.md).
3. Read the nearest nested `AGENTS.md`.
4. Read the applicable contract/profile/position.
5. Consult research, standards, references, examples, or templates only when relevant.

## Evidence discipline

README claims about commands, paths, versions, compatibility, capabilities, status, badges, installation, or support must remain backed by project evidence under the README Integrity Contract.

A popular template or external example is not evidence that the local project supports a feature.

## Artifact boundary

Templates under [`../templates/`](../templates/) and examples under [`../examples/`](../examples/) are artifacts. They may demonstrate READMEbasic knowledge but do not silently override contracts.

## Structural changes

Moving long-form knowledge under `docs/` is structural. Preserve substantive wording, update canonical paths/authority links, and record notable moves in the subsystem changelog.
