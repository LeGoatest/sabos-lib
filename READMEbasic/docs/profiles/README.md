# READMEbasic Profiles

> **Status:** Evolving profile domain  
> **Parent authority:** [`../README.md`](../README.md)

Profiles specialize READMEbasic for different repository audiences without turning one template into a universal structure.

Initial profile classes include:

- application;
- library/package;
- multi-system repository/monorepo;
- documentation/governance repository;
- subsystem/component.

Future profile files may capture section priorities, first-success expectations, status needs, documentation routing, and common anti-patterns for each class.

Profiles specialize README structure; they do not waive evidence or integrity contracts.

Use [`AGENTS.md`](AGENTS.md) for automated maintenance.
