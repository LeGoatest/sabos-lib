# READMEbasic Documentation

> **Status:** Canonical READMEbasic knowledge index  
> **Framework root:** [`../README.md`](../README.md)  
> **Agent instructions:** [`AGENTS.md`](AGENTS.md)

`READMEbasic/docs/` contains the governed knowledge behind evidence-based README design: contracts, practitioner positions, profiles, research, standards/platform guidance, references, terminology, best-practice synthesis, and supporting resources.

Reusable README starting material belongs under [`../templates/`](../templates/). Concrete comparative/illustrative material remains under [`../examples/`](../examples/).

## Domains

- `best-practices.md` — current synthesis of README structure and maintenance principles.
- `resources.md` — curated tools, specifications, examples, and references.
- `contracts/` — binding README integrity obligations.
- `positions/` — deliberate practitioner preferences and tradeoffs.
- `profiles/` — repository/audience-specific README profiles.
- `research/` — empirical and scholarly evidence.
- `standards/` — Markdown/GitHub/platform guidance and applicability.
- `references/` — historical/comparative source material.
- `glossaries/` — README/documentation terminology.

## Artifact boundary

- [`../templates/`](../templates/) contains reusable starting artifacts.
- [`../examples/`](../examples/) contains illustrative/comparative examples.

Neither templates nor examples become contracts merely because they are reusable or persuasive.

## Governing principle

> **Docs explain why and what. Templates provide a starting artifact. Examples demonstrate. Evidence controls claims.**
