# READMEbasic Template Agent Instructions

> **Status:** Binding for automated work under `READMEbasic/templates/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)

Templates are reusable starting artifacts. They MUST remain subordinate to READMEbasic contracts and project evidence.

Agents MUST:

- keep placeholders explicit until verified facts are available;
- avoid adding unsupported technologies, commands, badges, maturity, compatibility, or capabilities;
- preserve profile adaptability rather than optimizing the template for one repository type;
- keep the template concise enough to be a starting point rather than a duplicated reference manual;
- update related documentation when a template change reflects a deliberate READMEbasic position/contract change.

Agents MUST NOT treat template structure as mandatory merely because it is the current default artifact.

Notable template changes update [`../CHANGELOG.md`](../CHANGELOG.md).
