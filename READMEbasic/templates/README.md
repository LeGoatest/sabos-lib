# READMEbasic Templates

> **Status:** Reusable artifact layer  
> **Knowledge framework:** [`../README.md`](../README.md)  
> **Template agent instructions:** [`AGENTS.md`](AGENTS.md)

This directory contains reusable README starting artifacts derived from READMEbasic knowledge.

Templates are starting points, not universal contracts. A project must adapt a template to its actual audience, profile, commands, paths, maturity, capabilities, and evidence.

## Current template

- [`README-template.md`](README-template.md) — general evidence-aware README starting structure.

## Rules

- Remove irrelevant sections rather than leaving empty ceremony.
- Replace placeholders with verified project facts.
- Do not add badges, commands, compatibility claims, installation methods, or capabilities that the project cannot support with evidence.
- Use the applicable README profile under [`../docs/profiles/`](../docs/profiles/README.md).
- Follow the binding README Integrity Contract under [`../docs/contracts/`](../docs/contracts/README.md).
