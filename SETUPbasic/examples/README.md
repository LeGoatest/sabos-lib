# Site Structure Examples

All examples are **illustrative choices**, not generated starter projects and not claims about any live repository.

| Example | Combination | Purpose |
| --- | --- | --- |
| [Modular MVC PHP](modular-mvc-php.md) | One deployable app + MVC + capability-aware services | Evolve an existing CMS/CRM-style app |
| [Capability-driven Laravel](modular-ddd-laravel.md) | Modular monolith + DDD + layered/hexagonal + MVC at boundary | Domain-rich multiuser PWA/platform |
| [Static/marketing website](static-website.md) | Static or SSR content with assets and selectively dynamic endpoints | Lean lower-maintenance sites |

The primary difference among examples is **source ownership and framework needs**, not whether a model is objectively more modern. Avoid copying all example directories: create only directories backed by real functionality, tests or documentation.
