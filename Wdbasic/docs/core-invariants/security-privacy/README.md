# Security and Privacy Invariant

> **Status:** Binding core-invariant domain  
> **Parent:** [`../README.md`](../README.md)  
> **Detailed contract:** [`security-and-privacy.md`](security-and-privacy.md)

This invariant governs security and privacy outcomes independent of frontend framework choice.

Core expectations include server-side authorization and validation where applicable, least privilege, explicit field allowlists, safe structured APIs, contextual output encoding, CSRF/request-integrity decisions, secure upload handling, authentication/recovery, browser policy, third-party review, data minimization, retention, consent, telemetry, and incident evidence.

Security and privacy are gate conditions, not compensatory score dimensions.
