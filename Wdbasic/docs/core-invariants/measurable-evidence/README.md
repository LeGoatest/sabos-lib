# Measurable Evidence Invariant

> **Status:** Binding core-invariant domain  
> **Parent:** [`../README.md`](../README.md)

WDBASIC claims must remain traceable to actual evidence and the correct authority level.

## Evidence taxonomy

1. **External requirement** — named standard/specification with its original applicability and conformance language.
2. **External guidance/research** — informs practice but is not automatically a conformance requirement.
3. **Binding WDBASIC contract** — deliberately adopted WDBASIC requirement.
4. **Practitioner position** — deliberate preference/tradeoff kept separate from standards.
5. **Heuristic** — score, weighting, equation, or review shortcut not externally validated as universal.
6. **Unresolved historical finding** — known prior work that cannot be restated precisely without guessing.
