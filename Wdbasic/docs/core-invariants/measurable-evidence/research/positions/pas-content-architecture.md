# PAS Content Architecture Position

> **Status:** Practitioner position — conditional strategy, not universal page law  
> **Reviewed:** 2026-08-14  
> **Current strategy index:** [`../content-strategies/README.md`](../content-strategies/README.md)

This position preserves WDBASIC's Problem–Agitate–Solution (PAS) research while incorporating the 2026-08-14 adversarial audit.

PAS is **not** a Google ranking factor, a W3C requirement, an academic standard, or a mandatory WDBASIC sequence.

## 1. Applicability

Use PAS when:

- the user is meaningfully problem-aware;
- consequence framing adds factual decision value;
- the problem has real cost, delay, inconvenience, risk, or missed outcome;
- the solution benefits from explaining why the issue matters before action.

Do not force PAS when:

- the visitor is already solution-aware or transaction-ready;
- the page is primarily informational or comparison-driven;
- direct answer/offer/benefit communication better matches intent;
- agitation would require manufactured urgency or exaggerated fear.

WDBASIC now treats PAS as one strategy under [`../content-strategies/`](../content-strategies/README.md).

## 2. Hardened PAS interpretation

When PAS applies:

```text
Problem recognition
→ relevant consequence
→ credible solution
→ validation / evidence
→ objection resolution
→ appropriate action
```

The sequence may be distributed, compressed, or reordered when user intent warrants it. The semantic jobs matter more than a literal template.

### Problem

Help the intended visitor recognize why the content is relevant to their situation.

### Agitate / consequence

WDBASIC defines agitation ethically and narrowly:

> Explain only the relevant consequences, inconvenience, risk, cost, delay, or missed outcome that can be supported and that materially helps the user's decision.

Agitation is not permission to fabricate fear, scarcity, urgency, severity, or repeated pain statements.

### Solution

Explain what can be done, how the offered solution addresses the identified need, what outcome is reasonable, what limitations matter, and what the next step is.

## 3. Relevance law supersedes universal problem-first ordering

The earlier proposed law “problem precedes solution” was too rigid.

The hardened WDBASIC rule is:

> **Relevance precedes or accompanies persuasion.**

Valid sequences include:

```text
Problem-aware:
Problem → consequence → solution → proof → action

Solution-aware:
Solution → benefit → proof → action

Transactional:
Offer → CTA → proof → details

Comparison:
Criteria → alternatives → evidence → recommendation

Informational:
Answer → explanation → evidence → next step
```

## 4. Semantic anti-repetition rule

A later section should not merely paraphrase a semantic job already completed unless it introduces new:

- evidence;
- specificity;
- context;
- user questions;
- decision criteria;
- examples;
- task/buyer-stage relevance.

Repetition is not depth.

## 5. Historical PAS equations

### Generic weighted form

Earlier research represented PAS as:

```text
PAS = (wP × P) + (wA × A) + (wS × S)
```

No external source established canonical coefficients for this equation.

### Experimental `7/5/8` rubric

A later WDBASIC heuristic proposed:

```text
Problem = 7
Agitate = 5
Solution = 8
```

This reflected an editorial preference to emphasize helping and solving over emotional escalation. It was not empirically validated and is **not a current canonical score**.

### Unresolved first formula

The exact coefficients from the earliest exploratory PAS calculation remain unrecovered and must not be reconstructed by guessing.

## 6. EPPM / threat-efficacy boundary

Fear-appeal research is useful only as contextual evidence for consequence-heavy communication.

WDBASIC rejects any deterministic PAS rule such as:

```text
Efficacy - Threat >= 0
```

as a validated marketing threshold.

The practical qualitative review is simply:

- is the consequence factual and proportional?
- is the proposed response understandable and credible?
- does the message preserve user agency?

Do not present EPPM as a conversion formula.

## 7. Research interpretation

### Problem recognition

Bruner and Pomazal support the importance of problem recognition in consumer decision processes. This does not establish PAS as a universal page sequence.

Primary citation:

Bruner, G. C., & Pomazal, R. J. (1988). **Problem Recognition: The Crucial First Stage of the Consumer Decision Process.** *Journal of Consumer Marketing*, 5(1), 53–63. DOI: 10.1108/eb008219.

### Consequence and efficacy

Witte's Extended Parallel Process Model and later fear-appeal meta-analyses support careful attention to threat/consequence and efficacy, but the literature is not a license to create a deterministic PAS equation for commercial landing pages.

Tannenbaum et al. (2015) found an average positive effect for fear appeals and stronger results when efficacy statements were present, but the evidence is largely from risk/health communication and does not prove a universal local-service CRO rule.

Later meta-analytic work further complicates simple threat × efficacy assumptions. WDBASIC therefore uses the research qualitatively, not as a numerical gate.

## 8. Search and content evidence

Google Search guidance supports people-first usefulness, trust, intent alignment, clear subject coverage, and language people use. It does not mandate PAS.

Semrush guidance supports audience-led content, pain points, buyer-stage questions, trust, content gaps, conversion clarity, and CTA/intent alignment. It likewise does not establish PAS as a required universal architecture.

## 9. Component roles when PAS applies

| Component | Possible role |
|---|---|
| Hero | relevance + solution + action, or problem + solution + action |
| Problem section | problem recognition |
| Consequence section | factual consequence |
| Services/capabilities | solution |
| Process | solution + uncertainty reduction |
| Case study | solution + validation |
| Reviews/proof | validation |
| FAQ | objection resolution |
| Estimate/contact | action |

The component name does not prove the semantic job.

## 10. Position summary

WDBASIC keeps PAS because it can be useful, but hardens it with this boundary:

> Use PAS only when the user's intent and awareness make problem/consequence framing genuinely useful. Otherwise use the content strategy that best satisfies the task.

When PAS is used, agitation remains factual, proportional, and subordinate to user understanding and agency.
