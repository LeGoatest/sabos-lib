# Accessibility Agent Instructions

> **Status:** Binding under `core-invariants/accessibility/`  
> **Parent:** [`../AGENTS.md`](../AGENTS.md)

Preserve external WCAG claim language, manual-test requirements, accessibility-supported technology assumptions, complete-process scope, cognitive-accessibility distinctions, and non-web/native scope boundaries.

Never convert `cantTell`, untested, manual-pending, or failed accessibility evidence into a pass.
