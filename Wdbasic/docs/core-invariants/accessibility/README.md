# Accessibility Invariant

> **Status:** Binding core-invariant domain  
> **Parent:** [`../README.md`](../README.md)

WDBASIC is designed to support WCAG 2.2 Level AA where WCAG applies, while preserving exact external conformance language.

This domain owns web accessibility evidence, cognitive accessibility, media accessibility, native/hybrid and non-web scope, and browser/assistive-technology evidence.

- [`cognitive-accessibility.md`](cognitive-accessibility.md)
- [`media-accessibility.md`](media-accessibility.md)
- [`non-web-accessibility.md`](non-web-accessibility.md)
- [`compliance/`](compliance/)

Accessibility is not a point score. A known applicable failure remains a failure regardless of SEO, conversion, performance, or visual quality.
