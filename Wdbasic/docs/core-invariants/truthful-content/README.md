# Truthful Content Invariant

> **Status:** Binding core-invariant domain  
> **Parent:** [`../README.md`](../README.md)

Content must not manufacture evidence or manipulate users through unsupported claims.

Do not fabricate or imply unverified reviews, ratings, testimonials, awards, certifications, licenses, insurance, guarantees, customer logos, project counts, response times, success rates, statistics, availability, pricing, accessibility, security, privacy, sustainability, maturity, urgency, scarcity, or risk severity.

AI-assisted content must add evidence, specificity, context, or decision value rather than repeatedly paraphrasing the same claim. When evidence is missing, preserve the uncertainty or use an explicit placeholder rather than inventing proof.
