# WDBASIC Content Strategies

> **Status:** Applicability-controlled content strategy guidance  
> **Reviewed:** 2026-08-14  
> **Core dependency:** [`../core-invariants.md`](../core-invariants.md)

WDBASIC does not prescribe one persuasion sequence for every page. Content strategy must follow user intent, awareness, decision stage, task, risk, evidence, and page objective.

## 1. Strategy selection rule

Before selecting PAS, comparison, informational, transactional, or another strategy, determine:

- primary user intent;
- problem awareness;
- solution awareness;
- transaction readiness;
- decision complexity;
- risk/consequence relevance;
- evidence available;
- page objective;
- whether the user needs explanation, comparison, reassurance, proof, or action first.

A content strategy is a means to satisfy intent, not a mandatory visual template.

## 2. PAS when applicable

Use Problem–Agitate–Solution when the audience is meaningfully problem-aware and consequence framing adds decision value.

Typical fit:

- urgent or deteriorating property problems;
- preventable maintenance consequences;
- a user who recognizes a symptom but not the solution;
- situations where delay, cost, inconvenience, or risk is factual and material.

Avoid forced agitation when:

- the user is already solution-aware;
- the page is primarily comparison or education;
- the problem has little meaningful consequence;
- the copy would need manufactured urgency to make PAS work;
- direct offer/benefit communication better matches the task.

Detailed practitioner research is preserved in [`../positions/pas-content-architecture.md`](../positions/pas-content-architecture.md).

## 3. Comparison strategy

Use when the user's primary task is choosing between alternatives.

Typical sequence:

```text
Decision context
→ comparison criteria
→ options / tradeoffs
→ evidence
→ recommendation or fit guidance
→ action
```

Requirements:

- compare material criteria rather than cherry-picking favorable differences;
- disclose meaningful limitations;
- distinguish fact, inference, opinion, and practitioner preference;
- avoid fabricated competitor claims.

## 4. Informational strategy

Use when the user primarily wants to understand a subject, process, requirement, symptom, or question.

Typical sequence:

```text
Direct answer / orientation
→ explanation
→ examples or evidence
→ exceptions / caveats
→ related next steps
```

Do not force a sales problem into an informational query merely to create agitation.

## 5. Transactional strategy

Use when the user already knows the service/product and wants to act.

Typical sequence:

```text
Offer / task
→ essential terms or scope
→ CTA
→ trust / proof
→ process / expectations
→ objections / alternatives
```

For high-intent visitors, the solution or action may appropriately precede detailed problem framing.

## 6. Other intent models

WDBASIC may use other evidence-based or project-specific models when they better fit the task, including:

- navigational;
- local/service-area;
- compliance-driven;
- maintenance/planning;
- aspirational/improvement;
- troubleshooting;
- onboarding;
- retention/support;
- mixed-intent pages.

New strategies must document applicability, semantic jobs, failure patterns, evidence basis, and any conversion assumptions.

## 7. Relevance law

The hardened WDBASIC content law is:

> **Relevance precedes or accompanies persuasion.**

This supersedes the earlier proposed universal law that “problem precedes solution.”

Possible valid sequences include:

```text
Problem-aware:
Problem → consequence → solution → proof → action

Solution-aware:
Solution → benefit → proof → action

Transactional:
Offer → CTA → proof → details

Comparison:
Criteria → alternatives → evidence → recommendation

Informational:
Answer → explanation → evidence → next step
```

## 8. Semantic progression rule

Regardless of strategy, later sections must add at least one of:

- new evidence;
- greater specificity;
- new context;
- a new user question;
- a new decision criterion;
- a concrete example;
- a materially different stage of the task or decision process.

Repetition is not depth.

## 9. Content-strategy evidence boundary

- Google/Search guidance may support people-first usefulness, intent alignment, originality, and trust, but does not mandate PAS.
- SEO/CRO sources may support specific tactics, but WDBASIC strategy selection remains a practitioner synthesis.
- Academic consumer or risk-communication research must not be converted into marketing formulas beyond what the research actually establishes.
