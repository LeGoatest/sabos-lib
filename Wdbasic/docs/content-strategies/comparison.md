# Comparison Strategy

Use comparison structure when the visitor is evaluating alternatives, methods, providers, products, plans, materials, or approaches.

A useful progression is:

```text
decision criteria
→ relevant alternatives
→ meaningful differences / tradeoffs
→ evidence
→ suitability by scenario
→ recommendation or next action
```

Do not create false equivalence, hide material drawbacks, cherry-pick favorable differences, or manufacture a winner through asymmetric evidence.
