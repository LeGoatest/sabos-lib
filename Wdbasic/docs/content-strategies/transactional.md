# Transactional Strategy

Use transactional structure when the visitor already has high intent to contact, buy, book, request an estimate, register, download, or perform another concrete action.

A useful progression is:

```text
offer / outcome
→ primary action
→ essential eligibility / scope
→ trust / proof
→ process or friction reduction
→ objections / policy details
→ confirmation and recovery
```

Do not force unnecessary educational or agitation sections ahead of an obvious high-intent action.
