# Performance Evaluation

Evaluate performance with measurable evidence rather than impressions.

Where applicable, record field and/or lab evidence for Largest Contentful Paint (LCP), Interaction to Next Paint (INP), Cumulative Layout Shift (CLS), transfer/image/CSS/JavaScript/font/third-party budgets, request and processing latency, long tasks, render blocking, and constrained-condition failure/retry behavior.

When current Core Web Vitals thresholds are used, preserve their source, version/date, percentile, and whether evidence is field or lab data. Performance is a user-experience dimension, not proof of search ranking.
