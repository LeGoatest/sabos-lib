# Intent Alignment Evaluation

Evaluate whether the page matches the user's actual task, question, need, problem awareness, desired outcome, and decision stage.

Possible states include problem-aware, solution-aware, comparison/evaluation, informational/learning, high-intent transactional, navigational/support, and aspirational/exploratory.

The governing principle is:

> **Relevance precedes or accompanies persuasion.**

Do not force problem-first or PAS structure onto a query whose intent is better served by an answer, comparison, offer, tool, navigation path, or evidence first.
