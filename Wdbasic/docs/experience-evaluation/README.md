# WDBASIC Experience Evaluation

> **Status:** Diagnostic framework; non-compensatory  
> **Core prerequisite:** [`../core-invariants/README.md`](../core-invariants/README.md)

Experience evaluation asks how well a surface works **after** applicable core-invariant gates are resolved.

Use the diagnostic vector:

```text
[D, I, U, T, C, P]
```

Where:

- `D` = discoverability
- `I` = intent alignment
- `U` = usability
- `T` = trust
- `C` = conversion clarity
- `P` = performance

Do not collapse these dimensions into a universal compensatory total that can hide a critical weakness.
