# Tailwind / TCbasic Technology Profile

> **Status:** WDBASIC technology profile  
> **Reviewed:** 2026-08-14

Tailwind CSS is not a WDBASIC core requirement. When Tailwind is adopted, reusable styling architecture belongs to TCbasic and related project-specific conventions.

## Requirements

- Preserve semantic component/state naming where the project uses abstractions.
- Avoid JavaScript-owned responsive styling and dynamically assembled unbounded utility names.
- Keep accessibility, state, focus, contrast, validation, and responsive behavior aligned with native/ARIA/server state.
- Repeated visual values and roles should be governed consistently through tokens or approved abstractions.
- Do not present a WDBASIC/TCbasic styling preference as Tailwind's universal recommended authoring style.
