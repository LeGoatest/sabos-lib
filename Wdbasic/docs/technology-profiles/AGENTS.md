# Technology Profile Agent Instructions

> **Status:** Binding maintenance rules for `technology-profiles/`  
> **Parent:** [`../AGENTS.md`](../AGENTS.md)

Technology profiles specialize implementation without redefining core invariants.

Do not promote profile-specific mechanisms into universal WDBASIC law. When multiple profiles are combined, document their boundary and state ownership. Profile guidance must preserve accessibility, security/privacy, truthful content, HTTP/URL integrity, resilience, and measurable evidence.
