# Example: Lean Static / Server-Rendered Website

**Status:** Illustrative, adaptable to static HTML or a small PHP site.

~~~text
site/
├── src/
│   ├── pages/
│   ├── components/
│   ├── layouts/
│   ├── styles/
│   │   └── input.css
│   └── scripts/
├── public/
│   ├── images/
│   ├── icons/
│   └── fonts/
├── dist/                 # only if generated by a real build
├── config/
├── docs/
├── tests/
├── scripts/
├── README.md
├── AGENTS.md
└── CHANGELOG.md
~~~

A PHP SSR site may instead use app/, partials/, static/ and public_html/, reflecting its actual server root. Do not add dist/ unless build output exists; do not expose config or private runtime data from public. A static-first site can add isolated form handlers/functions without becoming a microservice platform.

**Performance and SEO:** rendering mode is not a substitute for semantic, accessible HTML, reliable URLs or content strategy. See [WDBASIC](../../Wdbasic/README.md) and [SEObasic](../../SEObasic/README.md).
