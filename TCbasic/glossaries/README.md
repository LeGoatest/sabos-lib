# TCBasic Glossary Index

> **Status:** Non-normative terminology reference

Glossaries explain recurring terms but do not override binding architecture, standards, build, token, component, or compliance contracts.

## Current glossary

- [`tailwind-css.md`](tailwind-css.md) — Tailwind CSS v4 directives, functions, source-detection terms, token terms, variants, layers, build adapters, and package terminology.

## Governance

A glossary entry should:

- Expand acronyms on first use.
- Identify whether a term belongs to Tailwind, CSS, TCBasic, npm, or a host framework.
- Mark legacy, deprecated, optional, or context-dependent behavior.
- Link to the governing contract or official reference.
- Avoid presenting a term or tool as proof of quality or conformance.

Binding documents must remain understandable without requiring the glossary.
