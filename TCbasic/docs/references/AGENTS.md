# TCBasic Reference Agent Instructions

> **Status:** Binding for work under `TCbasic/docs/references/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)

References preserve evidence, historical context, and project-specific source material. They are informative unless another governing document explicitly promotes a lesson into a position or contract.

Agents MUST:

- preserve the source context and material meaning;
- identify project-specific paths, tooling, branding, or assumptions;
- avoid rewriting history merely to match current TCBasic terminology;
- distinguish extraction of a reusable lesson from mutation of the original reference;
- link promoted positions/contracts back to supporting reference material when useful.

Agents MUST NOT treat a reference example as proof that every adopter should use the same implementation.
