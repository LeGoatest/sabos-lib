# TCBasic Glossary Agent Instructions

> **Status:** Binding for work under `TCbasic/docs/glossaries/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)  
> **Glossary entry point:** [`README.md`](README.md)

Glossaries clarify Tailwind CSS, CSS/platform, token, component, tooling, and TCBasic terminology. They are informative unless a binding contract explicitly adopts a definition.

## Rules

Agents MUST preserve distinctions between upstream Tailwind terminology, CSS/platform terminology, TCBasic-defined terminology, and general industry shorthand.

When an upstream framework owns a definition, identify the relevant version/scope when material.

Historical package/distribution terms may remain in a glossary when useful, but they must not imply that current SABOS Lib publishes TCBasic as a package.

Do not turn glossary text into new API or compatibility guarantees by implication.
