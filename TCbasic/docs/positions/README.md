# TCBasic Practitioner Positions

> **Status:** Evolving position domain  
> **Parent authority:** [`../README.md`](../README.md)

This directory records deliberate TCBasic preferences separately from upstream Tailwind guidance, industry convention, and binding package contracts.

Useful subjects include preferences about semantic classes, `@apply`, template readability, CSS-first architecture, build-adapter boundaries, naming, token layering, and framework independence.

A position should explain the practical rationale and tradeoffs, especially when TCBasic intentionally differs from common Tailwind usage.

A position does not change public package behavior by itself. Normative changes must update the controlling contract/API deliberately.

Use [`AGENTS.md`](AGENTS.md) for automated maintenance.
