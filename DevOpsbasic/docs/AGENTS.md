# DevOpsbasic Documentation Agent Instructions

Inherit `../AGENTS.md` and repository governance.

Preserve these knowledge types distinctly:

- branch/deployment contracts;
- provider guidance (GitHub, cPanel);
- framework guidance (Laravel);
- reusable workflow artifacts;
- project-specific deployment facts.

Do not generalize one project's cPanel paths, API token names, PHP/Node versions, build output, or deployment script into a universal DevOpsbasic requirement.

When provider behavior is material and potentially current-sensitive, verify it against current provider documentation before converting it into a new binding rule.
