# SEObasic Source Excerpt Agent Instructions

> **Scope:** `SEObasic/docs/evidence/historical-references/source-excerpts/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)

Files in this directory preserve source material whose exact wording or provenance matters.

Agents MUST:

- preserve verbatim excerpts exactly when a file is marked verbatim;
- preserve provenance/date/status metadata separately from the quoted source body;
- avoid silently correcting grammar, spelling, capitalization, punctuation, or terminology inside preserved source text;
- distinguish later interpretation from the original source;
- update [`../../../../CHANGELOG.md`](../../../../CHANGELOG.md) when source-reference structure changes materially.

Agents MUST NOT transform source excerpts into current normative authority by implication. Current authority must be established explicitly in the owning invariant, strategy, surface, measurement contract, practitioner position, or other canonical role document.
