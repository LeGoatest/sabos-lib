# SEObasic Evaluation

> **Role:** What is being assessed  
> **Parent:** [`../README.md`](../README.md)  
> **Agent instructions:** [`AGENTS.md`](AGENTS.md)

Evaluation is a cross-surface layer. It defines **what SEObasic is examining** before a strategy is selected or a result is interpreted.

## Current evaluation dimensions

SEObasic may evaluate, as applicable:

- **discoverability** — whether relevant users/systems can find the resource;
- **eligibility and indexability** — whether a surface can crawl, process, index, or otherwise include the resource under its documented rules;
- **retrieval and visibility** — whether the resource appears in observable search/answer retrieval or presentation;
- **intent alignment** — whether the page/content satisfies the actual user/task/query intent;
- **presentation and snippets** — titles, descriptions, previews, rich results, answer rendering, and similar presentation outcomes;
- **citation and attribution** — whether a source is referenced and how attribution is represented;
- **authority and trust** — evidence, identity, reputation, proof, and source-quality signals without collapsing third-party scores into platform truth;
- **local relevance** — geographic/business relevance and local-surface fit;
- **engagement** — observable interaction under a named platform definition;
- **conversion** — progress toward a defined business/user outcome;
- **technical performance** — measurable delivery, rendering, crawl, indexing, and performance behavior.

## Boundary

Evaluation is not a tactic list.

For example:

```text
"intent alignment is weak"
```

is an evaluation finding.

```text
"add an FAQ because FAQs rank"
```

is a proposed strategy/tactic and requires separate evidence.

Likewise, a poor metric does not establish its cause. Preserve the distinction between observation and mechanism under the [`Evidence Classification Contract`](../invariants/evidence-classification.md).
