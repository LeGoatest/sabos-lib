# SEObasic References Agent Instructions

> **Scope:** `SEObasic/references/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)

## Preserve historical truth

Agents MUST distinguish:

- verbatim source material;
- recovered historical facts;
- later summaries;
- inference;
- current normative guidance.

## Verbatim sources

Files explicitly marked as verbatim source excerpts MUST NOT be editorially improved, normalized, paraphrased, or silently corrected. Metadata and surrounding explanation may identify provenance and status without altering the source excerpt itself.

## Historical recovery

When a complete historical source is unavailable:

- record only details that can be recovered with confidence;
- identify recovery limitations;
- do not invent missing language or dates;
- do not rewrite older decisions to make them appear consistent with later terminology.

## Current authority

Historical examples may inform current contracts and practitioner positions, but a historical record becomes binding only through an explicit current adoption/canonicalization decision.

Material reference restructuring must preserve links/provenance and update [`../CHANGELOG.md`](../CHANGELOG.md).
