# SEObasic Practitioner Positions

> **Status:** Evolving position domain  
> **Parent authority:** [`../README.md`](../README.md)

This directory records deliberate SEObasic preferences and acknowledged practitioner bias separately from contracts, platform guidance, standards, research, and historical references.

A position may cover topics such as content ownership, local-search strategy, website-versus-platform priorities, channel roles, paid-media philosophy, measurement interpretation, internal linking, structured data, or content reuse.

Position records should preserve why the stance exists, what experience/evidence supports it, known tradeoffs, and where it differs from common SEO/marketing practice.

A position does not become a binding contract automatically. Stable obligations should be adopted through the relevant contract layer.

Use [`AGENTS.md`](AGENTS.md) for automated maintenance.
