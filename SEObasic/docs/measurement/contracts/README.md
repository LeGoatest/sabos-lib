# SEObasic Measurement Contracts

> **Status:** Binding contract registry for `SEObasic/measurement/`

Measurement contracts define stable semantics and reporting obligations for metrics used across search, local, web, social, paid, YouTube, and related analytics.

## Current contracts

- [`metric-semantics.md`](metric-semantics.md) — metric naming, source, scope, formula, attribution, geographic context, proprietary-score handling, and interpretation requirements.

Measurement contracts do not prescribe one analytics vendor. They define what must remain knowable and comparable regardless of provider.
