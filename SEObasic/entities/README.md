# SEObasic Entities

> **Scope:** Entity relationships, internal linking, backlinks, topical relationships, knowledge graphs, service/location relationships, and machine-readable entity consistency.

SEObasic treats links and structured relationships as a graph of meaningful entities rather than as a place to force keywords.

## Subject map

This domain can preserve knowledge about:

- canonical entities and identifiers;
- aliases and disambiguation;
- internal links and anchor context;
- backlinks derived from useful forward relationships;
- categories, tags, topics, authors, organizations, services, locations, projects, and case studies;
- service-to-location and service-to-proof relationships;
- entity extraction and reviewable link suggestions;
- graph diagnostics such as orphan pages or weak relationships;
- Schema.org identifiers and cross-surface entity consistency.

## Current canonical material

- [`entity-graph.md`](entity-graph.md) — current internal-link/entity-graph framework and safe extraction direction.

## Boundary

This domain governs semantic relationships. It does not authorize mass page creation, keyword stuffing, or automated link insertion that harms readability.

See [`AGENTS.md`](AGENTS.md) before automated changes.
