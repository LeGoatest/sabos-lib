# SEObasic Examples Agent Instructions

> **Scope:** `SEObasic/examples/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)

Examples illustrate adopted contracts; they do not define those contracts.

Agents MUST:

- identify the governing domain/contract for an example;
- keep example claims and output consistent with the current contract;
- avoid business-specific fabricated data when a neutral placeholder or clearly illustrative value is sufficient;
- validate executable examples when practical;
- update or deprecate examples when a governing contract changes.

Agents MUST NOT:

- infer a universal rule from one example;
- change a contract merely to make an old example pass;
- present illustrative metrics/results as measured outcomes.
