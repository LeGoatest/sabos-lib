# SEObasic Go Example Agent Instructions

> **Scope:** `SEObasic/examples/go/`  
> **Parent authority:** [`../AGENTS.md`](../AGENTS.md)

Go files in this directory are reference implementations, not the source of SEObasic contracts.

Agents MUST:

- read the governing technical/entity/measurement contract before changing example behavior;
- keep examples generic and parameterized where practical;
- preserve truthful structured-data behavior and error handling;
- validate executable Go examples when material code changes are made;
- update documentation/changelog when an example's public behavior materially changes.

Agents MUST NOT change a governing contract merely to preserve an outdated example.
