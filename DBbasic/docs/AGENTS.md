# DBbasic Documentation Router

> **Status:** Binding local agent routing
> **Scope:** DBbasic/docs/

Inherit [DBbasic/AGENTS.md](../AGENTS.md) and [repository governance](../../governance/README.md).

1. Identify whether a change is new research, vendor guidance, a position, a contract proposal, or illustrative implementation.
2. Cite original publications/vendor docs with version/date and scope where possible; do not treat scholar search results as peer-review evidence without checking the publication.
3. Keep generalized SQL and engine-specific syntax separate. Never label code engine-neutral without validating it.
4. Do not turn proposed obligations into binding MUSTs without a deliberate change-control decision.
5. Preserve the dated full research record; corrections belong in an annotated revision or evidence update, not a silent rewrite of historical findings.
6. Keep in-repo relative links accurate; update both knowledge routing and changelogs when authority paths change.
7. For technical claims, separate constraints that the database actually enforces from behavior delegated to app, identity provider, deployment, or operator.
